# Turvapoliitika

## Turvanõrkusest teatamine

**Ära ava turvanõrkuse kohta avalikku issue'd, arutelu ega PR-i.**

- **Avalikud repositooriumid:** kasuta repositooriumi vahekaardil **Security** nuppu **Report a vulnerability** (GitHubi privaatne turvanõrkuse teatamine).
- **Privaatsed repositooriumid:** teavita otse repositooriumi hooldajaid või organisatsiooni omanikke.

Lisa võimalusel:
- mõjutatud repositoorium ja versioon/commit;
- nõrkuse kirjeldus ja võimalik mõju;
- sammud probleemi taasesitamiseks.

Kinnitame teate kättesaamist esimesel võimalusel ja hoiame Sind lahenduse käiguga kursis.

## Saladused koodis

Kui märkad repositooriumis paroole, võtmeid, tokeneid või muud tundlikku infot, teavita kohe hooldajaid. Lekkinud saladus tuleb kehtetuks tunnistada ja välja vahetada — ainult commit'ist eemaldamisest ei piisa.

## Security policy (English)

**Do not report security vulnerabilities through public issues, discussions or pull requests.**

- **Public repositories:** use **Security → Report a vulnerability** (GitHub private vulnerability reporting).
- **Private repositories:** contact the repository maintainers or organization owners directly.

Please include the affected repository and version/commit, a description and impact, and steps to reproduce.

If you find credentials, keys or tokens in a repository, report them immediately. A leaked secret must be revoked and rotated; removing it from the commit history is not enough.
